# Command fix

Owner ID is configured as:
BOT_OWNER_ID=1293127492982407195

Prefix:
BOT_PREFIX=$

Owner commands:
$blacklist @user [reason]
$unblacklist @user
$blackliststatus [@user]

User commands:
$blackliststatus

Important: restart the bot after changing .env. Slash commands require DISCORD_CLIENT_ID and the bot must be invited with the `applications.commands` scope.
