# Mrs Orbie Premium Key System

- Premium keys are exactly 6 numeric digits.
- No trial system is included.
- `/premium-panel` / prefix `premium-panel` sends the activation panel; bot owner only.
- `/generatekey @user [duration]` / prefix `generatekey @user [duration]` creates an owner-generated key and DMs it when possible; bot owner only.
- Shop purchases for 7-day or lifetime Premium generate a one-time key linked to the buyer and attempt to DM it automatically.
- The key must be redeemed by the linked Discord account and can only be used once.
- Activation is performed from the Premium panel's **Activate Premium** button.
